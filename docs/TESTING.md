# Ручная проверка

Юнит-тесты покрывают автомат состояний. Всё, что зависит от поведения macOS, проверяется вручную по этому списку. Перед проверкой запусти в терминале длительную команду, например `while true; do date; sleep 5; done`, чтобы видеть, что фоновая работа не останавливается.

Логи: `log stream --predicate 'subsystem == "io.github.salemjanabil.KAPL"'`

## Главные риски (проверить первыми)

| # | Проверка | Ожидание | Результат |
|---|---|---|---|
| R1 | Lock Now → нажать клавишу | Системный диалог Touch ID/пароля **виден поверх** щита | |
| R2 | То же, приложить палец | Щит исчезает, рабочий стол на месте | |
| R3 | Во время блокировки прийти уведомлению (например, `osascript -e 'display notification "x"'`) | Баннер **не виден** поверх щита | |
| R4 | ⌘Tab, ⌥⌘Esc, ⌘Q, ⌘H, ⌘Space, ⌃↑ (Mission Control), свайпы тремя/четырьмя пальцами | Ничего не открывается, рабочий стол не показывается | |
| R5 | Фоновая команда в терминале | Продолжает печатать, пока Mac заблокирован | |

## Остальное

| # | Проверка | Ожидание | Результат |
|---|---|---|---|
| T1 | Отменить диалог Touch ID (Esc / Cancel) | Щит остаётся, счётчик ошибок не растёт | |
| T2 | Трижды неверный палец/пароль | Сообщение «Too many attempts», 30 с ввод игнорируется | |
| T3 | Шесть неудач | Включается системная блокировка macOS; после разблокировки macOS щита нет | |
| T4 | Подключить/отключить внешний монитор во время блокировки | Все экраны закрыты щитом | |
| T5 | Mac заблокирован 15+ минут (дольше таймера сна) | Не уснул, дисплей не погас | |
| T6 | `pmset -g assertions` во время блокировки | Видны утверждения KAPL; после разблокировки их нет | |
| T7 | Убить процесс: `pkill KAPL` (из SSH или второго пользователя) | Щит исчезает, Dock и меню вернулись, утверждения сна сняты | |
| T8 | Закрыть крышку от батареи | Mac засыпает как обычно | |
| T9 | «Quit KAPL» во время блокировки | Недоступно (меню скрыто, выход отменяется) | |

Заметки о поведении, которое отличается от ожиданий, записывай прямо в колонку «Результат».
